🎣 Auto Fish by BarabakaAuto Fish by Barabaka is an automated fishing helper for GTA V (RAGE MP, rmrp) with a clean user interface.The script tracks the hook movement on the first bar, clicks precisely in the center of the green zone, and instantly triggers a 15 CPS autoclicker for the second bar. Once the catch is complete, the bot automatically loops back to waiting for the hotkey.✨ FeaturesPrecision Timing: Automatically calculates target speed and offset to hit the center of the green zone.Fast Autoclicker: Multi-threaded 15 CPS clicker dedicated to Stage 2 minigames.Automatic Loop: Cycles seamlessly after each catch using hotkey triggers.Modern Interface: Dark-mode GUI built with PySide6 for process selection and status tracking.Zero-Setup Launcher: Includes a setup script that installs dependencies automatically.🚀 Quick StartDownload the Repository
Download all project files into a single directory.Launch via run.bat
Double-click run.bat. It will automatically check for Python, install required packages (PySide6, mss, numpy, requests), and launch the script.In-Game UsageOpen GTA V / RAGE MP.Select your game process from the application dropdown.Equip your fishing rod.Press F6 (default hotkey) to enable/disable the bot.⚙️ Configuration & FilesFileDescriptionauto_fish_by_barabaka(8).pyMain script with GUI and core logic.run.batOne-click installer and launcher script.requirements.txtList of Python dependencies.settings.txtOptions guide for modifying parameters.guide.txtEnglish and Russian user manual.❓ TroubleshootingClicks not registering in game: Run run.bat or the Python script as Administrator.Python not found: Ensure Python 3.9+ is installed on your system.
